# Phase 3 — ResolvedAgent IR

## Objective

Stabilize the first internal provider-neutral representation.

## Read

- `reference/IR.md`

## Tasks

1. Define the minimal `ResolvedAgent` type based on actual Phase 2 data.
2. Separate raw config types from resolved runtime-ready types.
3. Normalize absolute paths and validated configuration before adapter handoff.
4. Keep provider-specific options isolated in an opaque extension field only if already required.
5. Add schema validation and serialization tests where useful.

## Constraints

Do not add team graphs, schedulers, child agents, or ACP messages yet.

## Acceptance criteria

The same `ResolvedAgent` can be consumed by a fake adapter in tests without knowing whether the future runtime is Paseo, Claude, Codex, or ACP.
